# Django Backend

Бэкэнд проекта написан с использованием фрэймворка `Django`   

Для панели администратора использовался пакет `django-jet-reboot`

В качестве файлового хранилища используется `minio`   
Для связи с хранилищем `minio` используется `django-storages`

## Приложения

1. api

    Приложение api отвечает за предоставление RESTful интерфейса для взаимодействия с различными ресурсами системы. Оно обеспечивает связь между фронтендом и бэкендом, позволяя пользователям взаимодействовать с данными через стандартизированные API.

    Основные функции:

    * Аутентификация и авторизация пользователей с использованием токенов.
    * Предоставление доступа к данным о курсах, уроках, пользователях и другим сущностям.
    * Обработка запросов на получение, создание, обновление и удаление данных.

2. blog

    Приложение blog предназначено для управления контентом блога. Это может включать статьи, новости и другие публикации, которые связаны с тематикой курсов и IT-рекрутинга.

    Основные функции:

    *Создание и редактирование постов блога.
    *Управление тегами и категориями для упрощения навигации по контенту.
    *Отображение списка постов и их детальной информации для пользователей.

3. courses

    Приложение courses управляет всеми аспектами, связанными с курсами, предлагаемыми на платформе. Оно отвечает за создание и редактирование курсов, модулей и связанных с ними материалов.

    Основные функции:

    * Управление списком курсов, их описаниями и структурой.
    * Создание и редактирование модулей и уроков внутри курсов.
    * Загрузка и управление учебными материалами, такими как видео, тексты и другие ресурсы.

4. enrolls

    Приложение enrolls отвечает за регистрацию пользователей на курсы и управление их прогрессом. Оно связывает пользователей с курсами и отслеживает их успехи.

    Основные функции:

    * Регистрация пользователей на курсы.
    * Управление статусом прохождения курсов (например, завершенные, в процессе).
    * Ведение истории учебной деятельности пользователя.

5. homeworks

    Приложение homeworks используется для управления домашними заданиями, связанными с курсами. Оно позволяет преподавателям создавать задания и проверять выполненные работы студентов.

    Основные функции:

    * Создание и редактирование домашних заданий.
    * Загрузка студентами выполненных работ.
    * Оценка и обратная связь по выполненным заданиям.

6. lesson_tests

    Приложение lesson_tests управляет тестами, которые связаны с уроками в рамках курсов. Тесты могут использоваться для оценки знаний студентов и их подготовки к следующим этапам обучения.

    Основные функции:

    * Создание и редактирование тестов, связанных с уроками.
    * Управление вопросами и вариантами ответов.
    * Автоматическая проверка результатов тестов и их сохранение.

7. lessons

    Приложение lessons управляет отдельными уроками, которые составляют модули и курсы. Каждый урок может содержать видео, тексты и другие образовательные материалы.

    Основные функции:

    * Создание и редактирование уроков.
    * Привязка учебных материалов к урокам.
    * Управление порядком прохождения уроков внутри модуля или курса.

8. orders

    Приложение orders отвечает за управление заказами и оплатами на платформе. Оно связывает пользователей с их покупками и отслеживает статус заказов.

    Основные функции:

    * Обработка заказов на курсы и другие услуги.
    * Управление статусами оплат (например, оплачено, ожидает оплаты).
    * История транзакций пользователей.

9. tutors

    Приложение tutors управляет информацией о преподавателях и инструкторах, которые ведут курсы.

    Основные функции:

    * Создание и редактирование профилей преподавателей.
    * Привязка преподавателей к курсам и урокам.
    * Отображение информации о преподавателях на страницах курсов.
10. users

    Приложение users управляет учетными записями пользователей на платформе. Оно включает в себя функционал аутентификации, авторизации и управления профилем пользователя.

    Основные функции:

    * Регистрация и аутентификация пользователей.
    * Управление профилем пользователя (например, изменение данных профиля, пароля).
    * Назначение ролей и прав доступа для различных категорий пользователей.

11. views

    Приложение views занимается отслеживанием и логированием активности пользователей на платформе, таких как просмотры видео, использование материалов и другие действия.

    Основные функции:

    * Логирование просмотров учебных материалов и видео.
    * Анализ активности пользователей для улучшения учебного процесса.
    * Отчеты и статистика по использованию платформы.
